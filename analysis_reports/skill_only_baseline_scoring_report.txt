HEADLINE (rebuttal-ready)
==============================================================================
  dP-sign, n=49:  skill-doc-only LLM 3/49 = 6.1%   vs   always-predict-zero 45/49 = 91.8%   (LLM is 42 tasks WORSE than trivial)
  dominant SIP, n=40:  LLM 8/40 = 20.0%   vs   majority-class 14/40 = 35.0%   vs   prior-matched random 26.9%;  kappa = +0.037

CAVEATS (state these in the rebuttal):
  1. LOWER BOUND ONLY. This baseline never sees the two execution traces.
     Reviewer 2 asked for an LLM that READS BOTH TRACES; that experiment
     needs the raw .jsonl traces, which live only on the author machine.
     This result bounds how much is recoverable from the skill doc alone;
     it does NOT by itself establish that a trace-reading LLM would fail.
  2. The dominant-SIP comparison scores the LLM against CTA, not against
     human labels. Disagreement therefore CANNOT adjudicate which of the
     two is correct. It shows only non-recoverability, not CTA validity.
     The human gold set (meta-review priority 2) remains required.
  3. The dP-sign result is different in kind: it is scored against MEASURED
     unit-test pass rates, with no CTA involvement. That half is a clean
     ground-truth comparison and is the load-bearing number.
  4. Part of the SIP disagreement is a CTA detector prior, not LLM error:
     CTA emits procedural_scaffolding on only 11/522 fires (4/49 tasks)
     because PS is deliberately suppressed on unilateral_action
     divergences, whereas the document-only LLM predicts PS as dominant on
     17/40 tasks. Do not present the full gap as purely the LLM's failure.
  5. n is small (40 scoreable tasks, 1 instance/skill, r=1). CIs are wide.
